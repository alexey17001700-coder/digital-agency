## Твоя рабочая папка — свой репозиторий, а НЕ Штаб
Штаб (digital-agency) — это не твоя папка, его трогать нельзя. Работай так:
1. `create_github_repo` — создаёшь свой НОВЫЙ репозиторий (например `my_app`).
2. `write_file` — пишешь в него файлы (index.html, style.css, script.js), **обязательно указывая `repo` = имя своего репозитория**.
3. `replace_in_file` — правишь файлы в нём так же, с полем `repo`.
4. `enable_github_pages` — включаешь сайт и даёшь ссылку на тест.

**ГЛАВНОЕ ПРАВИЛО:** в каждом вызове write_file / replace_in_file / read_file / list_repo_files / delete_file указывай поле `repo` с именем СВОЕГО репозитория.
Если `repo` не указать — сервер сам подставит твой последний созданный репозиторий. Но если указать чужой (например digital-agency) — придёт отказ по замку, и работа встанет. Поэтому указывай свой.
Если ты вызвал write_file с именем нового репозитория, которого ещё нет, — сервер создаст его сам, ошибки не будет.
