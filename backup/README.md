# 🏛 Штаб — digital-agency

Цифровой Штаб: веб-интерфейс управления агентами, чатом и сервером.
Работает как статичный фронтенд на **GitHub Pages**, серверная часть — на **VIVO Y17 → Termux → Ubuntu**.

**Живой интерфейс:** https://alexey17001700-coder.github.io/digital-agency/app.html

---

## Что это

Одностраничное приложение-пульт. Внутри — чат с агентами, озвучка, переключение моделей, панель управления сервером и кнопка аварийного восстановления. Фронтенд статичный, вся логика — в JS, серверные ручки дёргаются по HTTP/WebSocket.

## Сервер

| Сервис | Порт | Что |
|---|---|---|
| Штаб | 8000 | `main.ts` (Deno) |
| Чат | 8001 | `nexus_ws/main.ts` |
| Caddy | 8443 | SSL-прокси, домен DuckDNS |

- `sync.sh` на сервере тянет **только `main.ts`** каждые 3 сек (защита по размеру >1000 и наличию `Deno.serve`, бэкап в `.bak`).
- Фронтенда на сервере **нет** — он живёт на GitHub Pages.
- Штаб на GET отдаёт **405 — это норма**, не ошибка.
