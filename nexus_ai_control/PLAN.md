## 🎙️ ЖИВОЙ РЕЖИМ (общение голосом)

- **Кнопка 🎤** — нажал → слушает всё время. Выключил кнопку → выключено.
- **Никакого фона, никаких слов-триггеров.** Только ручное включение/выключение.
- **Если Босс молчит** — тихо слушает + напоминает, что слушает (тихий индикатор/пик). Само не выключается.
- **Кнопка включена → всё голосом:**
  - ИИ отвечает голосом.
  - Не понял фразу → переспрашивает **голосом**.
  - Текстом править нельзя — руки заняты (например, за рулём).
- **Кнопка выключена → обычный текстовый чат.** Печатаешь руками, ИИ отвечает текстом.
- **Экран:** включил живой режим → экран горит **30 минут**. Потом экран гаснет, **микрофон продолжает слушать** — режим идёт дальше с выключенным экраном.
- **Озвучка:** ИИ читает ответ **целиком, как есть** (включая длинные). Сказал **«хватит»** → замолкает немедленно, слушание продолжается.

## 📱 УПРАВЛЕНИЕ ТЕЛЕФОНОМ

**Разрешено только два действия:**

1. **Навигатор** — маршрут. Работает из чата и голосом.
2. **Поисковик:**
   - **Прямой запрос по имени:** «открой Яндекс / Google / Chrome / <что-то>» → открывается именно названное.
   - **Без имени:** открывается **поисковик по умолчанию автоматически** — без диалога «чем открыть?».
   - **Если приложения нет на телефоне:** сказать — **«такого приложения у вас на телефоне нет»**.

**Всё остальное отложено** (звонки, сообщения, будильник, музыка, скриншот и т.д.) — расширяем только по слову Босса.

**Доступ к этим двум действиям — свободный.** Навигатор и поисковик работают **без отдельного разрешения, без PIN, без подтверждения**. Никаких уровней доступа для них не нужно.

## 🔐 ЗАЩИТА — ТРИ ЗАМКА

### 🔑 ГЛАВНОЕ: РЕЖИМ УПРАВЛЕНИЯ ТЕЛЕФОНОМ = ТАПЫ ПО ЭКРАНУ
- **Режим управления телефоном — это НЕ навигатор и НЕ поисковик.** Это отдельный режим, и включается он **конкретно тогда, когда включаются ТАПЫ ПО ЭКРАНУ** (удалённое нажатие/свайп).
- **Навигатор и поисковик — вне этого режима.** Работают свободно, без замков, режим для них не нужен.
- **Тапы по экрану ВЫКЛЮЧЕНЫ** → удалённого управления нет. Замков нет — потому что нет доступа.
- **Тапы по экрану ВКЛЮЧЕНЫ** → входим в режим управления телефоном, и **только тогда включаются замки**.
- Выключил тапы по экрану → всё разом закрылось, замки сняты вместе с доступом.
- **Замки не висят постоянно** — живут ровно столько, сколько включены тапы по экрану.

**Принцип: белый список, а не чёрный.** Разрешено только то, что Босс вписал руками. Всё остальное — не «запрещено», а **недоступно**.

### Замок 1 — СЕРВЕР (главный рубильник)
- Команды от ИИ идут через сервер Штаба. Сервер сверяет с белым списком **до** отправки на телефон.
- Нет в списке → команда даже не формируется.
- Телефон слушает только твой сервер, с твоим ключом.
- Белый список живёт на сервере — правится в одном месте (в Штабе).
- Каждая команда **подписана** секретным ключом. Телефон проверяет подпись.
- Журнал всех попыток (удачных и отклонённых) — на сервере, с телефона не стереть.

### Замок 2 — ТЕЛЕФОН (жёсткий замок в нативном слое)
- Проверка стоит **в глубине кода (Java)**, а не в интерфейсе — обойти интерфейс можно, нативный слой нет.
- Белый список хранится в **защищённом хранилище Android (Keystore)** — изменить только с телефона и только с PIN.
- **Нет универсальной команды «выполнить что угодно»** — только конкретные действия. Нет команды — нет дыры.
- Даже если сервер сломают и пошлют лишнее — телефон откажет.

### Замок 3 — ТЫ (живое подтверждение) — предложено, решение не принято
- Голос-пароль («Нексус, это я» / «подтверждаю»)
- Отпечаток / лицо перед опасным действием
- Кнопка «Подтвердить» с таймером (15 сек → отказ)
- Двойное согласие (PIN + голос) для самого опасного
- «Мёртвая рука» — нет касаний N времени → опасные разрешения гаснут сами
- Тревожная кнопка — одно слово/жест → все разрешения разом off, мост рвётся

**Пробить надо все три замка сразу.** Сломался сервер — телефон держит. Сломали телефон — без пальца/голоса пусто.
