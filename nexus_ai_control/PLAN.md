## 🎙️ 1. ЖИВОЙ РЕЖИМ (кнопка общения)

- **Кнопка 🎤** — нажал → слушает всё время. Выключил кнопку → выключено. Всё.
- **Никакого фона.** Никаких слов-триггеров. Никакого «Нексус, …». Только кнопка.
- **Если Босс молчит:** тихо слушает + напоминает, что слушает (тихий индикатор/пик). Само НЕ выключается.
- **Всё голосом.** Кнопка включена → ИИ отвечает голосом, переспрашивает голосом, если не понял. Босс текстом НЕ правит — руки заняты (например, за рулём).
- **Кнопка выключена** → обычный текстовый чат.
- **Экран:** включил живой режим → экран горит **30 минут**. Через 30 минут экран гаснет, **микрофон продолжает слушать** — живой режим идёт дальше с выключенным экраном.
- **Озвучка:** ИИ читает ответ **целиком, как есть** (включая длинные). Сказал **«хватит»** — замолкает немедленно, слушание продолжается.

### 🎨 ВИЗУАЛИЗАЦИЯ ЖИВОГО РЕЖИМА
- Нажал кнопку 🎤 → открывается **окошко на весь экран** (оверлей) поверх экрана.
- В центре — **кружочек, который шевелится** (пульсирует / дышит).
- Когда ИИ **отвечает** — кружочек **реагирует на голос**: колышется в такт речи, «изображает» его голос (визуализация амплитуды).
- Когда Босс **говорит** — кружочек тоже реагирует (в такт микрофону).
- Когда **тишина** — кружочек спокойно дышит, показывая, что слушает.
- **Внизу экрана ОДНА кнопка — ⬅️ «назад».** Кнопки микрофона внизу НЕТ. Выход из окошка — только «назад».
- Выключил кнопку → окошко закрывается.

## 📱 2. УПРАВЛЕНИЕ ТЕЛЕФОНОМ

Пока разрешено **только два действия**:
1. **Навигатор** (маршрут) — уже работает из чата.
2. **Поисковик** («найди…», «загугли…», «поищи…», «что такое…»).

Всё остальное (звонки, сообщения, будильник, музыка, скриншот) — **отложено**, расширяем только по слову Босса.

**Как открывается поисковик:**
- **Назвал приложение** («открой Яндекс / Google / Chrome») → открывается именно оно.
- **Не назвал** → открывается поисковик **по умолчанию** автоматически. Никакого диалога «чем открыть?».
- **Приложения нет на телефоне** → ИИ говорит голосом: «такого приложения у вас на телефоне нет».

**Работает и текстом (чат), и голосом (живой режим).**

## 🔐 3. ЗАЩИТА / ЗАМКИ

### Разделение режимов — НЕ ПУТАТЬ
| Режим | Замки |
|---|---|
| Открыть навигатор / поисковик | **Замков НЕТ.** Свободно. |
| Режим тапов по экрану | **Замки ВКЛЮЧАЮТСЯ.** |

**Правило:** замки включаются **только** вместе с режимом тапов по экрану. Не с навигатором, не с поиском. Только тапы.

### Когда спрашивается разрешение
- Замки включаются **только при режиме тапов по экрану**.
- Разрешение спрашивается **только тогда, когда ИИ реально управляет экраном и хочет открыть какое-то приложение**.
- **Разрешение — один раз при входе в приложение.** Подтвердил вход (палец/голос) → дальше в этом приложении свободно, пока режим тапов включён. На каждый тап НЕ спрашиваем.
- Просто открыть навигатор / поисковик (без тапов) — **никаких замков и разрешений**.

### 🔑 Режим управления телефоном (тумблер)
- **Выключен** → приложение вообще ничего не может с телефоном. Ни навигатор, ни поиск. Замков нет — потому что нет доступа.
- **Включён** → работают команды телефона, и только тогда включаются замки.
- Выключил режим → всё разом закрылось, замки сняты вместе с доступом.

### ⏱️ «Мёртвая рука» — 15 минут
- Нет касаний 15 минут → режим тапов гаснет сам, разрешения снимаются.

### Третий замок (голос-пароль + отпечаток)
- **Пока НЕ ставим.** Действия безопасные. Включаем позже, когда появятся реально опасные команды.

## 🔒 4. НАДЁЖНОСТЬ

- **Фоновый режим:** 30 минут экран горит → дальше экран гаснет, **микрофон продолжает работать** (фон).
- **Автозапуск:** НЕ нужен — приложение запускается руками.
- **Оффлайн:** нет интернета → навигатор и поиск не работают. Логично: нет сети — ничего не работает. Сообщаем «нет сети» и ждём.
