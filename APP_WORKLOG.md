# APP_WORKLOG — память проделанной работы

Журнал шагов по каждому приложению. **Читается без ключа администратора** — гостю доступно только чтение.
Пишет Архитектор после каждого выполненного шага.

## Правила ведения

1. Один раздел = одно приложение (имя репозитория).
2. Новые записи — **сверху** раздела, свежее первым.
3. Запись = версия/билд + что сделано + затронутые файлы.
4. Формат строки: `- <версия> — <шаг>: <результат>. Файлы: <список>`
5. Гость без ключа читает; изменять может только Архитектор.
