# CHAT_ARCHITECTURE — как устроен наш чат и разделённый экран

> Память Архитектора. Читать тихо, Боссу не пересказывать.
> Здесь — механизм нашего с Боссом общения и схема разделённого экрана
> (чат + Помощник). Обновлять при изменении потока сообщений или разметки.

---

## 1. КАК МЫ ОБЩАЕМСЯ (поток сообщений)

Штаб — это `digital-agency/app.html`. Чат встроен в него, отдельного мессенджера нет.

```
Босс пишет в #chatInput
        ↓
chat.js → sendMessage()
        ↓
POST https://shtab-boss.duckdns.org:8443   (PROXY, Caddy + SSL)
        ↓
main.ts (:8000) — выбирает модель, шлёт запрос провайдеру
        ↓
ответ возвращается в chat.js
        ↓
renderMessage() → .chat-container (лента чата)
```

**Ключевые точки:**
- `PROXY` объявлен в `chat.js` первой строкой: `https://shtab-boss.duckdns.org:8443`.
- История чатов — `localStorage`: `allChats`, `currentChatId`. Переживает F5.
- Модель выбирается кнопками в Штабе (платная / бесплатная 🆓), выбор хранится в `localStorage`.
- Ключи моделей — **на сервере**, в браузер не попадают.

**Сторожа авто-пинка (в `chat.js`):**
- `STALL_TIMEOUT_MS = 303000` — 300 с лимита запроса + 3 с запаса.
- `STALL_MAX_KICKS = 2` — больше двух пинок подряд не шлём (каждый пинок = отдельный платный запрос с полной историей).
- `KICK_GUARD_MS = 25000` — 25 с после пинка повторный запрещён.
- Метка пинка и счётчик лежат в `localStorage` (`shtabKickGuard_*`, `shtabStallKicks`) — после F5 дубля нет.
- Один счётчик на кнопке (`sendTimerLoop`, `sendStartTime`, `TIMER_MAX_MS = 330000`) — без наложения цифр.

**Этапы:** ответ заканчивается строкой `[ЭТАП N/M]` → скрипт сам шлёт «продолжи этап N+1». Последний этап — «Готово, Босс», метки нет.

## 2. РАЗДЕЛЁННЫЙ ЭКРАН: ЧАТ + ПОМОЩНИК

Панель Помощника стоит **рядом** с чатом, а не поверх. Диалог Босса с Архитектором остаётся видимым.

**Разметка (`app.html`):**
```
#chatSplit.chat-split
├── .chat-col-main        ← лента чата + поле ввода (наш диалог)
└── .chat-col-assistant   ← панель Помощника (#assistantBody)
```

**Стили (`style.css`, раздел «РАЗДЕЛЁННЫЙ ЭКРАН»):**
- `.chat-split` — `display:flex; flex:1 1 auto; min-height:0`.
- `.chat-col-assistant` — `display:none`, ширина `40%`, `max-width:520px`, `min-width:260px`.
- `.chat-split.split-on .chat-col-assistant` — `display:flex`. Класс `split-on` и есть «панель открыта».
- `@media (max-width:700px)` — `flex-direction:column`; чат `58%`, панель снизу `42%`, рамка сверху.

**Переключатель (`app.html`):**
```js
window.toggleAssistantPanel = function (on) {
    const sp = document.getElementById('chatSplit');
    const want = (typeof on === 'boolean') ? on : !sp.classList.contains('split-on');
    sp.classList.toggle('split-on', want);
    return want;
};
```
`ai.js` переопределяет `closeAssistantPanel` на свою версию — с остановкой авто-режима.

**Фронт Помощника (`ai.js`):**
- `build()` ищет `#assistantBody` и строит панель внутри колонки.
- `setPanel()` дёргает `#chatSplit` + класс `split-on`.
- Кнопка **🤖 Помощник** в панели режимов → `openAssistant()`.
- Шлёт `POST /ai` на шлюз `nexus_ws/ai.ts` (порт **8002**), автопоиск: `:8002` → `:8443` → `localhost:8002`.
- История Помощника — свой `localStorage`, с чатом Босса не пересекается.
- Мост `window.assistantAsk(text)` — Архитектор может передать задачу Помощнику, панель откроется сама.

## 3. КТО ЗА ЧТО ОТВЕЧАЕТ

| Файл | Роль |
|---|---|
| `app.html` | разметка, загрузка скриптов, `#chatSplit`, переключатель панели |
| `chat.js` | ядро чата: отправка, история, сторожа, этапы, версии |
| `style.css` | все стили, включая `.chat-split` и `.assistant-*` |
| `ai.js` | панель Помощника, авто-режим, связь со шлюзом :8002 |
| `ui.js` | интерфейс, модалки, кнопки |
| `network.js` | сеть, статус, пинг |
| `voice.js` | озвучка, лаборатория голосов |
| `agents.js` | 25 агентов, круглый стол |
| `main.ts` | сервер :8000 — **только по прямому приказу** |
| `nexus_ws/ai.ts` | ИИ-шлюз :8002 — роутер провайдеров + инструменты GitHub |

## 4. ПРАВИЛА РАЗДЕЛЕНИЯ

1. Помощник **не перекрывает** чат модалкой — только колонка справа/снизу.
2. На телефоне панель уезжает вниз, чат остаётся сверху — Босс всегда видит наш диалог.
3. Свернул панель → авто-режим Помощника останавливается (не жжёт лимиты в фоне).
4. Истории не смешивать: чат Босса и диалог Помощника — разные `localStorage`.
5. `main.ts` не трогать. Секреты — только в переменных окружения.
